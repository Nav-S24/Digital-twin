# Phase 2 — Vehicle Health Intelligence Engine

Rule-based engine/battery/vehicle health scoring, plus an ML-derived
health score and remaining-useful-life estimate.

## What changed from the original notebook deliverable

The original Phase 2 deliverable was a Colab notebook (`Implementation.ipynb`)
that wrote its source files to `/content/vehicle_health_engine` and only
ever ran interactively — it produced a static `Output.csv` but **no
callable API and no dashboard**, even though both are named as required
deliverables in the project roadmap. This package fixes that:

- `src/` — the notebook's scoring/feature-engineering/training logic,
  extracted verbatim and with the Colab-only hardcoded paths
  (`/content/vehicle_health_engine`, `sys.path.insert(...)`) replaced
  with a normal relative package layout.
- `train_models.py` — trains and saves the failure classifier (XGBoost)
  and RUL regressor (XGBoost) that the notebook defined but never
  persisted anywhere durable.
- `api.py` — **new**. A FastAPI service (`/score`, `/fleet/summary`,
  `/fleet/vehicle/{index}`, `/health`) wrapping the scoring logic.
- `dashboard.py` — **new**. A Streamlit dashboard (Fleet Overview +
  Live Scorer tabs) wrapping the same logic.
- `tests/` — **new**. 16 tests covering the scoring rules and the live
  API against the real trained models.

## ⚠️ Data provenance note

`data/Output.csv` (and therefore every score this API/dashboard returns
for the "reference fleet") was generated by the notebook's **synthetic
data fallback** (`utils.generate_synthetic_dataset`, seed=42), not the
real AI4I / Scania datasets the project's `Datasets.docx` specifies as
Phase 1/2 sources. The scoring *logic* is validated and correct — it's
been exercised against both this synthetic set and hand-built
sensor readings — but the numbers reflect a synthetic 2000-vehicle
fleet, not measured real-world telemetry. This same synthetic fleet
is what Phases 3, 4, 7, and 8 build on downstream, so it's consistent
across the whole project, just not "real" in the dataset-sourcing sense.

## Setup

```bash
pip install -r requirements.txt
python train_models.py        # trains & saves models/*.joblib (only needed once)
```

## Run the API

```bash
python api.py
# or: uvicorn api:app --reload
```
Visit http://localhost:8000/docs for interactive Swagger UI.

## Run the dashboard

```bash
streamlit run dashboard.py
```

## Run the tests

```bash
pytest
```
